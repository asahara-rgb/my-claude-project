# Webバナーセット

キャンペーン告知用のWebバナー一式（デザインソース）。

## 構成

| ファイル | サイズ | 用途 |
| --- | --- | --- |
| `Main.dc.html` | 1200×628 | OGP / SNSシェア画像 |
| `Square.dc.html` | 1080×1080 | Instagram等の正方形投稿 |
| `Leaderboard.dc.html` | 728×90 | ディスプレイ広告（リーダーボード） |
| `Rectangle.dc.html` | 300×250 | ディスプレイ広告（レクタングル） |
| `DirectionB.dc.html` | 1200×628 | 別案B：暖色ミニマル（明朝体） |
| `DirectionC.dc.html` | 1200×628 | 別案C：ポップ・高コントラスト |
| `canvas.json` | - | デザインキャンバス上の配置 |

## 差し替え箇所

角括弧 `[ ]` の部分は仮の文言です。

- `[キャンペーン名]`
- `[サービス名]`
- `[日付]` / `[特典内容]`
- `[ブランド名]`

## 確認方法

各 `.dc.html` はブラウザで直接開くと単体のHTMLとして表示できます。
フォントは Google Fonts（Zen Kaku Gothic New / Shippori Mincho B1 / Dela Gothic One）を読み込みます。
