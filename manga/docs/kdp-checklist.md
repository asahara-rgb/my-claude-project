# KDP 入稿・出版チェックリスト（コミック）

進めた項目は `[x]` にしてください。

## A. アカウント

- [ ] KDPアカウント作成（Amazonアカウントでログイン）
- [ ] 著者/出版社情報、支払い先（銀行口座）、税務情報（インタビュー形式）を登録
- [ ] ペンネームで出す場合は「本の詳細」の著者名欄で指定（アカウント名と別でOK）

## B. 原稿データ

- [ ] 本文画像が `pages/` に連番で揃っている（`python3 tools/check_pages.py` が OK）
- [ ] ページサイズが統一されている（既定 1600×2560、見開きは 3200×2560）
- [ ] 1画像 5MB 以下、全体 650MB 以下
- [ ] セリフ・重要な絵がセーフエリア内にある（端末で端が切れない）
- [ ] 文字がスマホ縦表示で読める大きさ（本文フキダシは 1600px 幅の原稿で 40px 以上目安）
- [ ] 扉ページ・奥付ページを入れた（奥付：タイトル / 著者 / 発行日 / 版 / 連絡先 / ©）
- [ ] 他者の著作物（フォント・素材・写真・ロゴ）の利用条件を確認した

## C. 表紙

- [ ] `cover/cover.jpg`：縦横比 1.6:1（推奨 1600×2560）、JPEG、RGB、50MB以下
- [ ] タイトル・著者名を画像に焼き込んだ（サムネイル縮小でも読める）
- [ ] 本文1ページ目に表紙を重複して入れていない（EPUB側で表紙として登録するため）

## D. EPUB 生成と確認

- [ ] `book.json` のタイトル・著者・言語・説明・識別子（UUID）を記入
- [ ] `python3 tools/prepare_pages.py` → `python3 tools/build_epub.py` でエラーなし
- [ ] （任意）`java -jar epubcheck.jar dist/xxx.epub` でエラー 0
- [ ] **Kindle Previewer 3** で開いて確認
  - [ ] 右開きになっている（ページ送りが右→左）
  - [ ] タブレット横向きで見開きが正しく組まれている（1ページ目が左、2ページ目が右）
  - [ ] スマホ縦向きで1ページずつ表示され、拡大しても粗くない
  - [ ] Kindle端末（E-ink）でモノクロの階調が潰れていない
  - [ ] 目次から表紙・本文開始へ飛べる

## E. KDP で本を登録（電子書籍）

### 本の詳細
- [ ] 言語：日本語
- [ ] タイトル / タイトルのフリガナ / サブタイトル（巻数）
- [ ] シリーズ登録（続刊予定があれば）
- [ ] 著者名 / フリガナ
- [ ] 内容紹介（HTMLの簡単な装飾可。冒頭2行で惹きつける）
- [ ] 出版に関して必要な権利：「私は著作権者であり…」を選択
- [ ] キーワード 7つ（例：漫画, コミック, 日常, コメディ, 短編, オリジナル, ○○好き）
- [ ] カテゴリー 2つ（コミック > ○○ など）
- [ ] 年齢層・成人向けコンテンツの有無

### 本のコンテンツ
- [ ] DRM：有 / 無 を選択（後から変更不可）
- [ ] 原稿：`dist/xxx.epub` をアップロード → 変換完了まで待つ
- [ ] 「固定レイアウト（コミック）」として認識されているか、オンラインプレビューで確認
- [ ] 表紙：`cover/cover.jpg` をアップロード
- [ ] ISBN：任意（電子書籍は不要）

### 価格設定
- [ ] KDPセレクト（90日間Amazon独占、Kindle Unlimited対象）に加入するか決める
- [ ] ロイヤリティ：35% か 70%（70%は日本ストアで 250〜1,250円 かつ KDPセレクト加入などの条件あり。最新条件を確認）
- [ ] 価格（配信コストは 1MB あたり加算されるため、画像容量を無駄に大きくしない）
- [ ] 予約販売（プレオーダー）を使うか

## F. 出版後

- [ ] 審査結果メール（通常72時間以内）を確認
- [ ] 商品ページで表紙・内容紹介・見本（なか見！検索）の表示確認
- [ ] 著者セントラル（Author Central）でプロフィール登録
- [ ] SNS用の告知画像を用意（`../banners/` のデザインソースが流用できます）
